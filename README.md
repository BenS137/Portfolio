## Projekte

### Jump N’ Stomp

**2-Spieler-Game · Godot · GDScript**

Kompetitives 2-Spieler-Game, bei dem sich die Spieler durch gezielte Sprünge und Stomps gegenseitig besiegen.

Mein Schwerpunkt im Projekt lag auf **Gameplay Programming, Debugging und der technischen Weiterentwicklung bestehender Systeme**.

→ [Projekt ansehen](JumpNStomp/)

### HdM-Mediathek

**Webanwendung · HTML · CSS · JavaScript · REST-API**

Webanwendung zur Darstellung von Projekten der HdM-Mediathek. Die Projektdaten werden dynamisch über eine REST-API geladen und auf Übersichts- und Detailseiten dargestellt.

Mein Schwerpunkt lag auf der **Webentwicklung, API-Anbindung und dynamischen Darstellung der Projektdaten**.

→ [Projekt ansehen](Mediathek/)

### Quiz-App

**Desktop-Anwendung · Python · PySide6**

Interaktive Quiz-Anwendung mit grafischer Benutzeroberfläche, zufälliger Fragenauswahl, Punktesystem, Timer und Ergebnisanzeige.

Das Projekt diente dazu, **Python, objektorientierte Programmierung und die Entwicklung grafischer Anwendungen** praktisch umzusetzen.

→ [Projekt ansehen](QuizzApp/)
